# Recording a speaker with the microphone

On the `Speakers` screen you can record a person directly with the microphone to
create a clean voice profile, or add a new sample to an existing profile.
Profiles created from a clean, single-person recording are recognized more
reliably than profiles created automatically from meetings. This requires the
profile write, analysis run and analysis read permissions.

1. Select **Create profile** and check that **Record with microphone** is selected.
   To add a sample to an existing person, use that person's **Add sample** button.
2. For a new profile, enter the person's name or nickname and choose the
   microphone.
3. Select **Start recording** and allow microphone access when the browser asks.
   Read the text that appears once recording starts in your natural voice, then say a few sentences
   freely. Aim for 45–60 seconds in total. Duration and level are shown.
4. Select **Stop and verify**. The recording is uploaded and verified, and the
   result appears in the same section. A created profile is added to the list.

Recording stops automatically at 120 seconds and is sent for verification.
Recordings shorter than 10 seconds, or with no sound from the microphone, are
not sent. If verification finds too little speech, inconsistent audio (more than
one person) or clipping, the reason is shown and **Record again** starts a new
attempt. After a connection error, keep the page open and use **Try again**; the same
recording is sent again. Verification continues on the server, so you can also
follow the result on the job page.

In a browser that cannot record, or outside a secure connection, **Upload a
file** remains available. A person can have at most 20 samples; audio retention
rules are the same as for file uploads.

# Sözlük

- **Artifact:** Sürümlü rule, skill veya guidance öğesi.
- **Bounded metadata:** Kaynak/secret taşımayan, açık şemayla sınırlandırılmış proje üst verisi.
- **Capability:** Tek başına teslim edilebilir ve bir PRD ile yetkilendirilmiş iş davranışı.
- **Deterministik bootstrap:** Pinlenmiş generator'ın aynı girdiden managed scaffold üretmesi.
- **Drift:** Kaynak otorite ile yerel/üretilmiş projeksiyon arasındaki fark.
- **Evidence provenance:** Bir sonucun kim/ne tarafından gerçekten yürütülüp kaydedildiği.
- **Intent bootstrap:** MCP blueprint'ini ajanın yerel araçlarla uyguladığı, byte-equivalence iddiası
  olmayan başlangıç.
- **Knowledge plane:** Blueprint ve yönetişim bilgisini sunan, workspace-blind MCP yüzeyi.
- **Managed file:** Generator'ın digest/state takibi yaptığı dosya.
- **Projection:** Aynı rule corpus'un istemciye özgü biçimi.
- **Reconciliation:** Kanonik artifact güncellemesini yerel ihtiyaca otorite sınıfıyla uyarlama.
- **Spec path:** Kabul edilmiş `specs/<domain>/PRDs/<capability>/PRD.md` yolu.
- **Streamable HTTP:** MCP'nin stateless, gateway arkasında kullanılan HTTP transport'u.

# Glossary

- **Artifact:** A versioned rule, skill or guidance item.
- **Bounded metadata:** Project metadata limited by an explicit schema and containing no source or
  secrets.
- **Capability:** Independently deliverable business behavior authorized by one PRD.
- **Deterministic bootstrap:** A pinned generator creating managed scaffold output from the same input.
- **Drift:** A difference between source authority and a local/rendered projection.
- **Evidence provenance:** Who or what actually executed and recorded a result.
- **Intent bootstrap:** An agent applying an MCP blueprint with local tools without a byte-equivalence
  claim.
- **Knowledge plane:** The workspace-blind MCP surface serving blueprint and governance knowledge.
- **Managed file:** A file whose digest/state is tracked by the generator.
- **Projection:** A client-specific representation of the same rules corpus.
- **Reconciliation:** Adapting a canonical artifact update to local needs under authority rules.
- **Spec path:** The accepted `specs/<domain>/PRDs/<capability>/PRD.md` path.
- **Streamable HTTP:** The stateless MCP HTTP transport deployed behind a gateway.

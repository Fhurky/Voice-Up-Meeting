# Verification records / Doğrulama kayıtları

This directory separates dated observations from durable product guidance. A passing result applies
to the recorded version and environment; it is not a permanent claim for future clients, models or
dependencies.

Bu dizin, tarihli gözlemleri kalıcı ürün rehberinden ayırır. Geçen bir sonuç yalnız kaydedilen sürüm
ve ortam için geçerlidir; gelecekteki istemci, model veya bağımlılıklar için sürekli garanti değildir.

- [Test matrix / Test matrisi](test-matrisi.md)
- [Source verification register / Kaynak doğrulama kaydı](kaynak-dogrulama-kaydi.md)

Executable repository tests remain authoritative. The HTML portfolio report is the decision-facing
summary; this directory records how to interpret and refresh its evidence.
